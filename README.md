# RideConnect Website

A beginner-friendly static website starter for a taxi/car-rental marketplace.

## Pages
- Home
- Book a Ride
- Services
- Fleet
- About
- Portfolio
- Contact
- Become a Partner

## Important
GitHub Pages can host the front-end static website. It does not provide the server-side database, authentication, payments, live driver matching or commission ledger needed for a production marketplace.

Recommended Phase 2: connect Supabase (database + authentication + APIs) or another backend, then add customer/driver dashboards, booking status, pricing, commission calculations, notifications and admin tools.
